# 🌱 Croply – Smart Irrigation Advisor

An AI-powered Smart Irrigation Advisor that helps farmers optimize water usage by predicting irrigation requirements based on crop, soil, and environmental conditions. Built using Machine Learning and Streamlit, the system provides intelligent recommendations to support sustainable agriculture.

---

## 🚀 Features

- 💧 AI-based irrigation prediction
- 🌾 Crop-specific recommendations
- 🌱 Soil and fertilizer analysis
- 📊 Interactive Streamlit dashboard
- 📚 Knowledge Hub for farmers
- ⚡ Fast and user-friendly interface

---

## ⚙️ Installation

```bash
git clone https://github.com/shreyaberlikar/Croply-Smart-Irrigation-Advisor.git

cd Croply-Smart-Irrigation-Advisor

pip install -r requirements.txt

streamlit run Home.py
```

---

## 📈 Workflow

1. Collect agricultural input data.
2. Preprocess and encode features.
3. Train the Random Forest model.
4. Predict irrigation requirements.
5. Display recommendations through Streamlit.
